# Таблицы пасхалки «Контекстно»

Игра: угадать слово, называя другие слова. На каждое игра отвечает его **местом**
в списке, отсортированном по смысловой близости к загаданному: 1 — это оно и
есть, 30 000 — «совсем не туда».

Все четыре файла собраны заранее скриптом `build-tables.py`. **На сервере нет
ни модели, ни Python** — бэкенд (`tables.js`) читает готовые байты.

| Файл | Что это | Размер |
|---|---|---|
| `vocab.txt` | какие слова принимаются; порядок строк = id слова | 30 000 слов, 530 КБ |
| `answers.txt` | из чего загадывается; порядок строк = номер строки в `ranks.bin` | 366 слов |
| `ranks.bin` | `uint16` LE, матрица `answers × vocab`: место слова к этому ответу | 22 МБ |
| `forms.txt.gz` | «словоформа лемма», чтобы принимать «машиной» и «детей» | 296 тыс. пар, 1,1 МБ |

`ranks.bin` не поднимается в память: место слова — это два байта по смещению
`(строка ответа × 30000 + id слова) × 2`, то есть одно чтение с диска на попытку.
Полная строка (60 КБ) читается только для «сдаюсь» и подсказок.

## Откуда взято

Модель [RusVectores](https://rusvectores.org/ru/models/)
`araneum_upos_skipgram_300_2_2018` (веб-корпус, 300 измерений, CC-BY 4.0), из неё
берутся только существительные — 86 861 штука в порядке частотности.

Дальше словарь чистится морфологией `pymorphy3`, и это половина всей работы:

* только нарицательные существительные в начальной форме — иначе в словарь лезут
  обрывки («машин», «трас»), имена и топонимы («серега», «москва»);
* `is_known` — то, что морфология знает, а не угадала по концовке: без этого
  четвёртым по близости к «группе» стоит «груп», и игрок думает, что это опечатка
  в его собственном вводе;
* `normal_form` сверяется без «ё»: в модели её нет вовсе, и иначе выпадают
  «ребенок», «елка», «звезда» — то, что назовут первым;
* ручной стоп-лист на мат, порнографию и наркотики: это рабочий инструмент.

Загадываются первые 366 слов очищенного словаря (то есть самые известные), минус
служебно-абстрактные вроде «вид» и «случай», которые не угадать в принципе.

## Как пересобрать

```bash
curl -sSLO https://rusvectores.org/static/models/rusvectores4/araneum/araneum_upos_skipgram_300_2_2018.vec.gz
pip install numpy pymorphy3
python3 build-tables.py araneum_upos_skipgram_300_2_2018.vec.gz
```

Минут пять, из них четыре — скачивание модели.

**Без нужды пересобирать не стоит.** Любая правка словаря меняет ранги у всех
аккаунтов разом: у человека, который вчера подобрался к слову на 12-е место,
сегодня то же слово окажется на 300-м.
