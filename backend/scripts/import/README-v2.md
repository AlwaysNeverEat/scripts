# Полный импорт и backfill (Windows)

Новый конвейер запускается двойным кликом по `run-import.bat` и рассчитан на
обычный Windows-компьютер. Нужен только Node.js LTS; Docker, Python и локальный
PostgreSQL не требуются. Доступ к базе идёт через Supabase Management API по
HTTPS.

## Порядок работы

1. `scrape-motul-all.js` получает текущий список **всех марок категории
   «Легковые автомобили»** Motul и запускает чекпоинтный импорт каждой марки.
   Поэтому новые марки и новые модификации находятся при следующих запусках.
2. `scrape-rolf.js` добавляет допуски.
3. `import-cars.js` вставляет новые машины, не перезаписывая ручные записи.
4. `build-enrichment-workset.js` добавляет в рабочий набор старые строки БД, у
   которых отсутствует `kw`, `bhp` или отдельный фильтр `vf/mf/sf`.
5. `scrape-filters.js` подбирает MANN-FILTER.
6. `scrape-big-filter.js` дозаполняет оставшиеся поля через BIG FILTER.
7. `fill-filters-by-engine.js` без сети раздаёт найденные **масляные** фильтры
   машинам с тем же кодом двигателя и объёмом — в том числе другой марки
   (один мотор ставят на разные модели и бренды). Воздушный и салонный по
   мотору не копируются: они зависят от кузова/платформы, а не от двигателя
   (принудительно — `--all`, но это уже на свой страх). Расхождение артикулов
   внутри одного кода = отказ копировать. Прогон посмотреть без записи:
   `--dry-run`.
8. `apply-enrichment.js` обновляет только пустые поля. Существующий артикул,
   мощность и ручная отметка `absent:true` не изменяются.

Промахи и неполные результаты MANN перепроверяются раз в 30 дней
(`MANN_RETRY_DAYS`), BIG FILTER — раз в 14 дней (`BIG_RETRY_DAYS`). Для
немедленной проверки можно использовать `--force` у соответствующего этапа.

## Запуск

```text
backend\scripts\import\run-import.bat
```

При первом запуске будет запрошен Supabase access token. Конфигурация хранится
в `%USERPROFILE%\.cars-import.json`. Логи находятся в
`data\import\logs\pipeline.log`.

Скрипт можно остановить закрытием окна и позже запустить снова: Motul,
результаты каталогов и импорт используют чекпоинты/кэш. Если этап завершился
ошибкой сети, конвейер ждёт `PIPELINE_SLEEP` секунд (по умолчанию 600) и
повторяет проход.

## Почему fallback MANN → BIG

GoodWill указывает отдельный online-каталог, но на момент реализации у него не
было достаточно стабильного и проверяемого server-side API/HTML-контракта.
Каталог LYNX зависит от клиентского JavaScript. Они намеренно не используются
для автоматической записи: сомнительное совпадение хуже пустого поля. BIG FILTER
имеет серверные страницы с моделью, кодом двигателя, периодом, кВт/л.с. и
артикулами, поэтому его можно безопаснее сопоставлять без Chromium/Playwright.

Матч BIG отклоняется при конфликте непустых кодов двигателя и при близких
неоднозначных кандидатах. Без кода требуется совпадение модели и близкий объём;
мощность и годы усиливают оценку. Для кириллических старых записей применяются
общие синонимы и транслитерация проекта.
