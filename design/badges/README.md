# Значки после ника: модератор и поддержавший

Две анимации пришли архивом `icons.zip` (WebM, 400×400, ~1,3 с): галочка в
розетке — модератор, звёздочка — «сапорт», то есть поддержавший проект. В сайте
они лежат в `frontend/src/assets/badges/` как `mod.webm` и `supporter.webm`,
рядом — статичные `mod.png` и `supporter.png`.

## Почему статичная картинка отдельно

Значок играет только по наведению или клику, один раз (`nameBadges.js`). В
разметке всё остальное время стоит PNG — ПЕРВЫЙ КАДР анимации. Видео на каждый
ник означало бы десятки декодеров на странице топа ради того, на что никто не
смотрит.

## Белый фон

У присланных анимаций фон белый и непрозрачный (альфа-канала в WebM нет).

- PNG сделан прозрачным при сборке: кадр «разсмешан» с белым — для каждого
  пикселя непрозрачность `a = max(1 − r/255, 1 − g/255, 1 − b/255)`, цвет
  `(c − 255·(1 − a)) / a`. Чёрные линии и фиолетовый остались, белое ушло.
- У видео фон убирает CSS (`.nbadge` в `style.css`): в светлой теме
  `mix-blend-mode: multiply`, в тёмной `invert(1) hue-rotate(180deg)` + `screen`.

## Пересобрать PNG

ffmpeg не нужен — хватает Chromium из Playwright: открыть страницу с `<video>`
на нужном файле, перемотать на 0, нарисовать кадр на холст 96×96, пройти по
пикселям формулой выше и сохранить `toDataURL('image/png')`. Так и были
собраны нынешние картинки.

Если пришлют анимацию уже с прозрачным фоном — смешивание в CSS станет не
нужно, его надо будет убрать, иначе в тёмной теме значок инвертируется.
