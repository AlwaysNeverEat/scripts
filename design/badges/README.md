# Значки после ника: модератор и поддержавший

Две анимации пришли архивом `icons.zip`: галочка в волнистой розетке (модератор,
`mod.webm`) и звёздочка — «сапорт», то есть поддержавший проект
(`supporter.webm`). WebM 400×400, около 1,3 с.

**На сайте стоят не они, а перерисовка** — SVG в `frontend/src/nameBadges.js`,
анимация — CSS (`.nbadge` в `frontend/src/style.css`). Первая версия ставила сами
видео (статичный первый кадр + видео на время проигрыша), и вышло плохо по двум
причинам:

- линия у анимаций волосяная: в двадцать пикселей у ника значок читался серым
  пятнышком, а увеличение делало его только чуть заметнее;
- фон у анимаций белый и непрозрачный — его приходилось убирать смешиванием в
  CSS, и в тёмной теме фиолетовая галочка от инверсии становилась почти белой.

Перерисовка повторяет формы и движение оригиналов:

| Значок | Форма | По наведению / клику |
|---|---|---|
| Модератор | розетка с двенадцатью волнами, галочка внутри | розетка проворачивается, галочка прорисовывается заново |
| Поддержавший | пятиконечная звезда | сжимается, распрямляется с лёгким поворотом, вокруг вспыхивают лучи |

Цвет — смысл, а не акцент сайта: модератор зелёный (как прежняя плашка «mod»),
поддержавший золотой (как звезда панели «Поддержали проект»). Розетка и звезда
посчитаны формулой (`r(θ) = 9.2 + 0.85·cos 12θ` для розетки, R = 8.8 и r = 4.3
для звезды), а не обведены по кадру — так они ровные при любом размере.

Оригиналы лежат здесь как исходники: придёт новая анимация — сверять движение с
ними.
