# Фишки пасхалки «Маджонг» — исходник

Здесь лежит присланный лист `tiles-sheet.png` (1024×1024 RGBA) как есть: все
фишки набора, разложенные по смыслу — три масти рядами по девять, ветры,
драконы, цветы и времена года, — с подписями, рамкой и на тёмно-зелёном фоне.

В игре он не используется: из него собирается ОДИН спрайт
`frontend/src/assets/mahjong-tiles.png` (сетка 7×6, 616×660, ~200 КБ), и именно
он попадает в сборку. Сорок два файла по фишке — это сорок два запроса при
открытии окна и сорок два повода промахнуться на пиксель при нарезке.

## Раскладка спрайта

Клетка — 88×110, внутри неё фишка стоит от отступа в один пиксель. Строка и
столбец считаются прямо из `KINDS` в `shared/mahjong.js`
(`spriteRow`/`spriteCol`), таблицы соответствия «фишка → картинка» нет нигде:

|   | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| 0 | точки 1–7 | | | | | | |
| 1 | точки 8–9, бамбук 1–5 | | | | | | |
| 2 | бамбук 6–9, символы 1–3 | | | | | | |
| 3 | символы 4–9, ветер востока | | | | | | |
| 4 | ветры юга/запада/севера, драконы, слива | | | | | | |
| 5 | орхидея, хризантема, бамбук, времена года | | | | | | |

То есть подряд, слева направо и сверху вниз, в порядке `KINDS`. **Порядок
менять нельзя, не пересобрав спрайт.**

Сорок третья фишка на листе (в строке драконов их четыре) — ПУСТАЯ, и в спрайт
она не попадает: рубашки в пасьянсе-маджонге нет, все фишки лежат лицом вверх с
первой секунды.

## Лицо и бортик — разного размера

У фишки нарисовано лицо (78×98) плюс бортик вправо и вниз, поэтому картинка
шире и выше шага сетки. Так и задумано: соседняя фишка встаёт ШАГОМ ЛИЦА и
закрывает бортик собой — видно его только у крайней в ряду, как у настоящей
горки, где внутри ряда фишки прижаты друг к другу. Числа лежат в одном месте —
`SPRITE` в `shared/mahjong.js`, — и оттуда их берут и окно игры, и сборщик.

## Как пересобрать

ImageMagick и cwebp на сервере нет и не нужно — рядом лежит `prepare.mjs`:

```bash
node design/mahjong-tiles/prepare.mjs
```

Скрипт сам находит фишки на листе (связные пятна «не фон»), проверяет, что их
ровно 43 и что они складываются в строки 9-9-9-8-8, выравнивает каждую по её
ЛИЦУ (по внешнему контуру фишки разъехались бы: снизу справа он шире на бортик)
и снимает фон. Фон снимается не «в лоб»: маска сжимается на пиксель, а снятое
кольцо дорисовывается цветом соседа изнутри с половинной прозрачностью — иначе
по контуру остаётся тёмно-зелёная кайма, заметная на светлой теме сайта.

Если лист перерисуют и раскладка изменится, скрипт скажет об этом, а не
нарежет пустоту.

После пересборки проверить: `npx vite` → `/dev-mahjong.html`.
