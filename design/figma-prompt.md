# Промпт для Фигмы: сайт «База рассчитанных машин»

---

Спроектируй веб-приложение «База рассчитанных машин» — внутренний инструмент
автосервиса по замене масла. Операторы ищут машину, видят готовый расчёт
стоимости замены масла по всем агрегатам и копируют текстовый отчёт в CRM.

Пожелания по стилю: тёмная тема (сейчас используется тёмно-синий фон с
оранжевым акцентом, но можешь предложить своё), современно, компактно —
это рабочий инструмент, оператор пользуется им десятки раз в день.
Desktop-first, но нужна и мобильная версия. Язык интерфейса — русский.

## Экран 1: Поиск

- По центру: логотип, заголовок «Калькулятор замены масла», подзаголовок
  «Найди машину — получи готовый отчёт для Битрикса».
- Большое поле поиска с плейсхолдером «Например: KIA Rio 1.6 2017 или киа рио…»
  (поиск понимает русский ввод и опечатки).
- Под полем — выпадающий список результатов (до 20). Каждая карточка:
  - 1-я строка (жирная): МАРКА МОДЕЛЬ · код двигателя
  - 2-я строка (приглушённая): объём л · кВт / л.с. · годы выпуска (2011–2019 или 2015+)
- Состояния: «К сожалению, такой машины ещё нет в базе», «Ошибка подключения
  к серверу».

## Экран 2: Страница машины

Верхняя панель: кнопка «← К поиску» и короткое название машины.

### Шапка-карточка машины
- Крупный заголовок: МАРКА МОДЕЛЬ (+ поколение мелче, если есть).
- Ряд чипов-бэйджей: двигатель (например «M 271.910»), код двигателя
  (моноширинный), объём «1.8 л», мощность «156 л.с.», топливо
  «бензин/дизель», годы «2007+».
- КРУПНЫЕ предупреждающие плашки (красные/оранжевые), если есть:
  «⚠ АКПП полную не делаем», «⚠ Фильтра в поддоне нет»,
  «⚠ Этому роботу расчёт не делаем». Их должно быть невозможно не заметить.
- Заметка оператора (если есть): цитата-блок, например
  «📝 сливная пробка под квадрат 8мм».
- Свёрнутый блок «Что рекомендовали при сохранении (N)» — раскрывается в
  список масел с ценами (это история, справочно).
- Справа сверху кнопка «✏ Нашли ошибку?» — включает режим редактирования.

### Панель настроек расчёта
- Переключатель пробега (сегмент-контрол): «до 100т» / «100т+» / «200т+» / «0W-20».
- Два тумблера: «🔓 Игнорировать допуска» (оранжевый), «🪣 С картером (+550₽)».
- Переключатель промывки ДВС: «без промывки» / «5-минутка» / «полная».

### Блок «Фильтры ДВС»
- Три строки: вф (масляный), мф (воздушный), сф (салонный).
- В каждой: бэйдж с артикулом (клик = скопировать), цена.
- Кнопка «✏ изменить» открывает мини-форму: артикул, цена, тип работы
  (селект: «защёлки 350₽ / болты 600₽ / разбор 1200₽»), галка «вкл».
- Если фильтров нет — кнопка «➕ Добавить фильтры ДВС».

### Карточки агрегатов (список)
Возможные агрегаты: «ДВС (двигатель)», «АКПП» или «Вариатор (CVT)», «МКПП»
(или «Робот/АМТ (расчёт как МКПП)»), «Раздаточная коробка», «Дифференциал
(перед/зад)». У каждой карточки:
- Заголовок с чекбоксом включения в расчёт + объём справа («5.8л» / «полн: 12л»).
- Поле «Объём» с ручной правкой, рядом формула расчёта мелким текстом
  («5.5 + 0.3 (фильтр) = 5.8л», для АКПП «7×0.6=4.20л → 4.2л (мин 4)»).
- Варианты масел (обычно 2): выделенная карточка с названием
  («Liqui Moly Leichtlauf HC 7 5W-30»), вязкостью, ценой «2000₽/л»,
  итогом «итого 11600₽» и бэйджами допусков:
  - зелёный бэйдж = допуск совпал с требованием машины («MB 229.3»),
  - синий бэйдж = покрывает требуемый через иерархию («MB 229.51 ⊃ MB 229.3»),
  - «+9 ещё» — раскрыть остальные допуски масла.
  - ⭐ у масла = соответствует регламенту марки (тултип с описанием).
  Вторая строка всегда SPOT (наш бренд) — по регламенту.
- Кнопка «🔄 выбрать масло (14 подходящих)» → раскрывающийся список всех
  кандидатов: ⭐, название, метки «✓ 2» (прямые совпадения) / «⊃2» (по
  иерархии), цена ₽/л; текущее масло подсвечено; кнопка «✕ закрыть».
- Для АКПП дополнительно: переключатель «частичная / полная (150%)»,
  чекбоксы «Фильтр (+1700₽)», у вариатора — «грубый (+1700₽)» и
  «тонкий (+3350₽)».
- Возможные предупреждения внутри карточки: «⚠ Введи объём заправки АКПП —
  Motul не дал», «⚠ Ни ZIC, ни ROLF не покрывают спецификации этой коробки —
  перевести клиента на мастера», «⚠ HIGH GEAR — передай мастеру».
- Свёрнутый блок «▸ Допуска машины (N)» — теги всех допусков.

### Блок «Итого»
- Кнопка «+ Добавить строку итого». Каждая строка итого — карточка:
  заголовок «Стоимость #1: 18 890₽» (+ вариант «+ 550₽ картер = …»),
  внутри по каждому включённому агрегату радио-выбор: масло 1 / масло 2 /
  «не включать». Кнопка ✕ удалить строку.

### Правая панель «Итог для Битрикса» (на десктопе — прилипшая колонка справа)
- Заголовок + кнопка «⧉ Копировать» (после клика — «✓ скопировано»).
- Моноширинный текстовый отчёт, многострочный, примерно такой:
  ```
  MERCEDES C 180 M 271.910 2007 156лс

  двс (5.8л)
  вф W 712/95 - 750₽ (защёлки 350₽)
  Liqui Moly Leichtlauf HC 7 5W-30 2000₽/л = 11600₽ + 550р (с\у\з\к)
  SPOT OPTIMAL 5W-30 1450₽/л = 8410₽ + 550р (с\у\з\к)

  акпп (серв 7л)
  част (4.2л / 60%) + работа 1210₽ + фильтр 1700₽
  ZIC ATF Multi 1400₽/л = 9340₽
  ```
- На мобильном панель уезжает вниз под калькулятор.

## Экран 3: Режим редактирования («Нашли ошибку?»)

Заменяет шапку-карточку формой:
- Заголовок «✏ Редактирование машины», справа кнопки «Отмена» и «💾 Сохранить».
- Секция «Машина»: сетка полей — Марка*, Модель*, Поколение, Двигатель,
  Код двигателя, Объём л, Год с*, Год по, кВт, л.с., Топливо.
- Секция «Объёмы жидкостей»: строка на агрегат (ДВС, АКПП/вариатор, МКПП,
  Раздатка, Диф. перед/зад) с числовым полем «л».
- Секция «Допуски масла»: textarea, по одному в строке.
- Секция «Фильтры ДВС»: три строки: подпись, поле артикула, чекбокс «отсутствует».
- Секция «Особенности обслуживания»: чекбоксы «АКПП полную не делаем»,
  «Фильтра в поддоне нет», «Этому роботу расчёт не делаем», «Этому вариатору
  расчёт не делаем».
- Секция «Какие масла предлагать этой машине»: список масел по вязкостям
  (5W-30, 5W-40, 0W-20, 10W-40), каждое с галочкой; подпись «Снятая галочка
  убирает масло из предложений. Масла SPOT идут по регламенту всегда».
- Секция «Заметка»: textarea.
- Блок ошибки сохранения (красный).

## Мелкие элементы

- Тост (правый нижний угол): «✓ Машина добавлена в базу / обновлена» +
  ссылка «Открыть страницу машины ↗».
- Баннер нотификатора (встраивается на чужие сайты, левый нижний угол):
  зелёная круглая галочка, заголовок «Эта машина уже рассчитана», подстрока
  «FORD FOCUS 1.6 — открыть расчёт ↗», крестик закрытия. Компактный,
  не перекрывает контент.
