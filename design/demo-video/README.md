# Демо-ролик K-Spot под «Тыдыщ!»

Ролик на 40 секунд под первую минуту песни Фиксиков «Тыдыщ!»: куплет — боли
оригинальной CRM, припев — на каждый «Тыдыщ!» удар и экран K-Spot.

Интерфейс в ролике НАСТОЯЩИЙ, а не нарисованный: клипы сняты с дев-песочниц
сайта (`frontend/dev-*.html`) живым Chromium. Нарисована только старая CRM — её
в песочницах нет, и показывать её настоящую (с адресом и данными) в ролике,
который пойдёт наружу, незачем.

| Файл | Что делает |
|---|---|
| `capture.cjs` | снимает клипы из песочниц: курсор, клики, набор текста |
| `rec.cjs` | общая часть съёмки: CDP-скринкаст с таймкодами, свой курсор |
| `index.html` | композитор: кадр — чистая функция от времени, `renderAt(t)` |
| `render.cjs` | гоняет композитор кадр за кадром и склеивает mp4 через ffmpeg |
| `fonts/` | Unbounded, Inter, JetBrains Mono (SIL OFL) — рендер в сеть не ходит |

## Как собрать

Нужны: запущенный vite фронта, playwright (стоит глобально), ffmpeg с libx264
(подойдёт `npm i ffmpeg-static` в любой временной папке) и сам трек — он в
репозиторий не кладётся.

```bash
cd frontend && npx vite --port 5173 &          # песочницы
cd design/demo-video
NODE_PATH=$(npm root -g) node capture.cjs /tmp/clips            # все клипы, ~1 мин
NODE_PATH=$(npm root -g) node capture.cjs /tmp/clips records    # или один
FFMPEG=/путь/к/ffmpeg NODE_PATH=$(npm root -g) \
  node render.cjs --clips /tmp/clips --audio tydysch.mp3 --out kspot.mp4
# отдельные кадры для проверки, без ffmpeg:
NODE_PATH=$(npm root -g) node render.cjs --clips /tmp/clips --out /tmp/stills --stills 4.3,22.8,40
```

Посмотреть в браузере с музыкой: отдать папку любым статическим сервером,
открыть `index.html?play&clips=<путь к клипам>&audio=<путь к mp3>` и кликнуть.

## Что стоит помнить

- **тайминги сняты с трека, а не на глаз.** Темп 114 BPM, «Тыдыщ!» стоит ровно
  через такт: `22.68 + k · 2.105` с (8 ударов, последний — финальный логотип).
  Строки куплета и «Раз, два, три» — по вокальным атакам (распознавание слов
  плюс спектральный поток). Поменяешь трек — пересчитывай `HIT0`, `LINES` и
  `COUNT` в `index.html`, всё остальное считается от них;
- **четвёртого «Тыдыщ!» (29.00) в куплете нет** — на этом месте в песне уже
  «Раз» второго припева. Смена сцены там есть, штампа нет;
- **кадр — функция от времени**, `Date.now` и `Math.random` в композиторе нет
  (случайность — сидом от номера удара). Поэтому ролик детерминирован и
  рендерится с любой скоростью;
- **время клипа ≠ время ролика.** Сцена припева длится такт (2,1 с), а
  действие в песочнице — дольше: `map` в `SCENES` — кусочно-линейная кривая
  «секунда сцены → секунда клипа», ею же делается ускорение набора и заполнения
  формы. `cam` — куда смотрит камера в CSS-пикселях клипа 1600×900;
- **в песочнице «Клиент» лежит снимок настоящих страниц CRM** — имя, телефон,
  госномер клиента и ФИО мастеров. `capture.cjs` подменяет их выдуманными прямо
  в отдаваемой странице (`anonymizeClient`); встроенный скрипт vite отдаёт
  отдельным модулем (`dev-client.html?html-proxy…`), поэтому перехват — по
  регулярке, а не по точному адресу. Новая песочница с живыми данными — туда же;
- **утверждения про CRM в ролике — из CLAUDE.md**, а не для красного словца:
  четыре страницы до чека, чек по ссылке, общий логин без автора, `duration=150`
  → три слота вместо пяти, галка СМС, включавшаяся сама. Придумывать новые
  «боли» не надо — ролик покажут людям, которые с этой CRM работают.
