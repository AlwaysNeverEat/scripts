# Картинки карт

Файл с именем карты — и карта нарисована. `strike.png` → «Удар», `guard.png` →
«Защита»; имена карт (id) лежат в `shared/roguelikeContent.js`. Никакой таблицы
соответствий в коде нет: окно само подхватывает всё, что здесь лежит
(`import.meta.glob` в `frontend/src/roguelike.js`), а карты без файла рисуются
вёрсткой.

Что рисовать, каких размеров и почему поля со стоимостью, уроном и описанием
обязаны остаться ПУСТЫМИ — `design/roguelike-cards/README.md`.

Форматы: `.png`, `.webp`, `.jpg`. Пропорция 795 × 1100 (её же отдаёт генератор
карточек).
