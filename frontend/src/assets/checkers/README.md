Картинки доски и шашек. Руками сюда ничего не кладут: файлы режутся из
присланного листа скриптом `design/checkers-board/prepare.mjs`, там же — README
с раскладкой и требованиями к исходникам.

Окно игры подхватывает их по имени файла (`light`, `dark`, `man-light`,
`man-dark`, `king-light`, `king-dark`), таблицы соответствия нет нигде. Файлов
нет — доска рисуется цветом, а шашки кружками; это рабочее состояние, а не
поломка.
