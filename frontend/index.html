Как установить скрипт
  1. Поставь расширение Tampermonkey (Chrome / Firefox / Edge).
  2. В Chrome зайди в chrome://extensions и включи Режим разработчика — без него скрипты не запускаются. В Firefox ничего включать не нужно.
  3. Жми «Установить» — Tampermonkey сам откроет свой экран, там нажми Install / Установить.

Обновляются скрипты потом сами — переустанавливать не нужно.
